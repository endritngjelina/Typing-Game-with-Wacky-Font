# ⌨️ Typing Game with Wacky Font

A browser-based typing speed and accuracy game where the challenge is cranked up — 
you have to type text displayed in a deliberately wacky, hard-to-read font! 
Each level is a standalone HTML file with no setup required.

---

## 🎮 About the Game

**Typing Game with Wacky Font** puts your typing skills to the ultimate test by 
rendering the target text in unusual, distorted, or decorative fonts that make 
reading (and typing) much harder than usual. Players must correctly type what they 
see on screen as quickly and accurately as possible.

This project is great for:
- Students building typing speed and focus under pressure
- Teachers looking for a fun, competitive classroom activity
- Anyone who wants a creative twist on traditional typing games

## 🚀 How to Play

1. Clone or download this repository.
2. Open any `Typing Game with Wacky Font #.html` file in your web browser.
3. Read the wacky-fonted text displayed on screen.
4. Type it out as accurately and quickly as you can.
5. Get scored on your speed and accuracy!

No server, framework, or dependencies needed — just open and play!

## 📚 Use in the Classroom

Each level is self-contained and can be assigned individually to students. 
Levels increase in font difficulty and text complexity, making this a 
progressive activity perfect for keyboarding, language arts, or computer 
literacy classes.
